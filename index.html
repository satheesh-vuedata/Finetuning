What is quantization?

Quantization stores each model weight with fewer numerical values. It reduces memory, but very low bit widths can slightly reduce precision. In QLoRA, the quantized base is used for the forward pass while the adapter learns the task.

QLoRA in four moves

The simulation separates the two ideas that make QLoRA efficient: shrinking the stored base model and limiting which parameters the optimizer can change.

1

Start with knowledge

A pretrained model already contains broad language patterns and task knowledge in its base weights.

2

Compress the base

Quantization stores weights with fewer bits. The forward pass still uses the base model, but it needs less memory.

3

Add a low-rank path

LoRA represents the task-specific update as two small matrices. Rank controls the adapter capacity.

4

Update only the adapter

Backpropagation computes gradients, while the optimizer changes the adapter and leaves the base weights frozen.
